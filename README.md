# My Portfolio

A personal portfolio website built with Next.js, React, and Tailwind CSS. It showcases my projects, skills, and experience, with sections for an about page, work history, and a contact form powered by MongoDB and Resend.

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- MongoDB
- Resend

## Features

- Animated hero and section transitions
- Project showcase with live demos and source links
- Contact form with email delivery and database persistence
- Responsive layout for desktop and mobile
